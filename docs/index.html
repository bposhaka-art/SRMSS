✨ Key Features

Role-Based Access

Admin, Supervisor, and Operator roles with granular permissions and authentication.

🚗

Fleet Management

Complete vehicle inventory, utilization tracking, and maintenance scheduling.

📍

Live GPS Tracking

Real-time vehicle tracking on interactive maps with speed monitoring.

Trip Scheduling

Schedule trips with conflict detection and status management.

📊

Analytics & Reports

Dashboard with charts, performance metrics, and operational insights.

Approval Workflow

Manage fuel logs and maintenance requests with approval system.

🚀 Quick Start

Installation

git clone https://github.com/bposhaka-art/SRMSS.git cd SRMSS pip install flask python app.py

Application will run on: http://localhost:5000
